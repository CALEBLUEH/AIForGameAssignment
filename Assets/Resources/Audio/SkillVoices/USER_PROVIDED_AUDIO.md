# User-provided skill voices

These fifteen MP3 files were recorded and supplied by the project owner on
2026-09-24 from their own Blue Archive gameplay footage. Each of the five
characters has three voice variants.

Runtime mapping:

- `Yuuka/`: Yuuka character skill
- `Ayane/`: Ayane character skill
- `Mika/`: Mika character skill
- `Momoi/`: Momoi character skill
- `Hina/`: Hina character skill

The game randomly selects one variant for each successful character-skill cast.
All character voices share one dedicated audio channel, so a newly cast skill
stops and replaces any unfinished voice. Playback pitch remains at `1` during
slow motion, pause-like skill cinematics, and battle speed changes.

The recordings may still contain third-party character dialogue. No separate
redistribution licence or attribution text was supplied, so the project owner
should confirm redistribution rights before publishing the game or repository.
